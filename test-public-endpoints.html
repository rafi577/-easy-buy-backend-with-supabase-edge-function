Important Notes

  • Public Endpoints (No Auth Required):
    • POST /admin-login - Admin authentication
    • POST /create-order - Create a new order
  • Protected Endpoints (Require JWT Token):
    • GET /get-orders - Get all orders
    • GET /get-order - Get single order
    • PUT /update-order - Update order
    • DELETE /delete-order - Delete order
    • POST /dispatch-order - Dispatch to Steadfast
    • GET /track-order - Track order
    • GET /dashboard-stats - Dashboard statistics
  • Before Testing:
    1. Make sure Supabase is running: supabase start
    2. Make sure functions are deployed locally: supabase functions serve
    3. Make sure the orders table exists in your database
    4. Disable RLS on orders table OR add policies for anonymous access
